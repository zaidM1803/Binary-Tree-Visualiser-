# 🌳 Binary Tree Visualizer

A simple and interactive web application that helps visualize how binary search trees work. Easily insert, search, and explore how nodes are structured and traversed in real-time with smooth animations.

---

## 🔍 What is a Binary Search Tree?

A **Binary Search Tree (BST)** is a special kind of binary tree where each node contains a value such that:

- The left subtree has values **less than** the parent node.
- The right subtree has values **greater than** the parent node.
- Each node can have **at most two children**.

BSTs are widely used in data structures and algorithms due to their efficiency in searching, insertion, and deletion operations.

---

## 🚀 Features

- Add nodes interactively
- Search for values and see the path visually
- Smooth animations for insertion and search
- Clear or randomly fill the tree with a number of nodes
- Adjustable animation speed
- Drag to pan and scroll to zoom in/out
- Auto-adjust layout for better visualization

---

## 🛠 Tech Stack

- **p5.js** – Used for creating and rendering canvas-based visualizations
- **JavaScript** – Core logic and interactivity
- **HTML/CSS** – Structure and basic styling

## Usage Instructions

Follow these steps to run the project locally and start visualizing your own binary trees:

### 🔧 Setup

1. **Clone the repository**

2. **Open the project**
Simply open the index.html file in any modern browser.
No build tools or frameworks needed — it runs entirely in the browser!
